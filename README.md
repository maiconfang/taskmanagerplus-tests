# 🧪 TaskManagerPlus - UI Automated Tests

This repository contains **UI automated tests** for the **TaskManagerPlus** application, built with **Playwright + TypeScript**.  
These tests validate the main user flows, such as login and navigation, and generate structured reports that can be analyzed by AI through the companion project **[TaskManagerPlus-AI-Analyzer](https://github.com/maiconfang/taskmanagerplus-ai-analyzer)**.

---

## 🚀 Project Overview

- **Framework:** [Playwright](https://playwright.dev/)
- **Language:** TypeScript
- **Execution Modes:** Local & CI
- **Reports:** JSON format (stored in `reports/ui/playwright-report.json`)
- **Purpose:** Provide reliable, maintainable automated UI tests for TaskManagerPlus and feed data to AI-driven analysis.


## Run test
PS C:\Desenvolvimento\workspace\taskmanagerplus-tests\ui-tests\tests> npx playwright test
